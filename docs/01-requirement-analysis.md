# Contract Lifecycle Management System (CLM)

## Project Overview

The Contract Lifecycle Management (CLM) System is a web application built using the Frappe Framework to manage the complete lifecycle of legal contracts within an organization.

The system enables organizations to create, review, approve, version, sign, execute, and manage contracts efficiently while maintaining a complete audit trail and integrating with Documenso for electronic signatures.

---

# Problem Statement

Organizations often manage contracts manually using emails and shared folders, resulting in:

- Poor version control
- Lack of collaboration
- No centralized tracking
- Difficult approval workflows
- No signature visibility
- Missing expiry reminders

This project aims to solve these problems by providing a centralized Contract Lifecycle Management system.

---

# Objectives

The application should allow users to:

- Create and manage legal contracts
- Maintain contract versions and amendments
- Collaborate with legal teams
- Approve contracts through internal workflows
- Send contracts for electronic signatures
- Track signing status
- Manage counterparties
- Provide a portal for external users
- Generate reports and dashboards

---

# Personas

## Contract Manager

Responsible for:

- Creating contracts
- Managing versions
- Sending contracts for approval
- Sending contracts for signatures
- Managing amendments

---

## Collaborator

Responsible for:

- Reviewing contracts
- Providing comments
- Suggesting modifications

---

## Approver

Responsible for:

- Reviewing contracts
- Approving
- Rejecting
- Requesting changes

---

## Counterparty

External user with no Desk access.

Can:

- View contracts
- Review contracts
- Approve or reject
- Sign contracts

---

## Administrator

Responsible for:

- User management
- Permissions
- System configuration
- Integration management
