# Contract Lifecycle Management System

A Contract Lifecycle Management (CLM) application built using the Frappe Framework.

## Features

- Contract Management
- Version Control
- Approval Workflow
- Collaboration
- Counterparty Portal
- Electronic Signatures (Documenso)
- Reports
- Dashboard

## Tech Stack

- Frappe Framework v16
- Python
- MariaDB
- Redis
- Documenso API
